# Дельта спецификации

## Purpose

Определяет, как конечная точка отправки анкеты превращает ответы посетителя и загруженный файл в промпт для языковой модели, чтобы сгенерированный ответ отражал то, что посетитель действительно отправил.

## ADDED Requirements

### Requirement: Выбранные ответы доходят до промпта дословно
Конечная точка SHALL включать в промпт, отправляемый языковой модели, то значение, которое посетитель выбрал для каждого вопроса с вариантами выбора, в каждой ветке анкеты.

#### Scenario: Выбрана цель из списка
- **WHEN** посетитель выбирает цель из предложенного списка
- **THEN** промпт содержит эту цель дословно
- **AND** промпт не содержит её общую замену

#### Scenario: Выбраны свет и погода из списка
- **WHEN** посетитель выбирает условие света или погоды из предложенного списка
- **THEN** промпт содержит это условие дословно
- **AND** промпт не содержит его общую замену

#### Scenario: Выбрана роль или время суток из списка
- **WHEN** посетитель выбирает роль или время суток из предложенного списка
- **THEN** промпт содержит это значение дословно

#### Scenario: Выбран вариант «другое» со своим текстом
- **WHEN** посетитель выбирает вариант «другое» и вводит собственный текст
- **THEN** промпт содержит собственный текст посетителя
- **AND** промпт не содержит его общую замену

### Requirement: На незаполненные вопросы не утверждается ничего
Когда посетитель не приводит значения для вопроса, конечная точка SHALL NOT утверждать в промпте ответ на него. Она SHALL либо опустить этот вопрос в промпте, либо явно пометить его как незаполненный.

#### Scenario: Условия света и погоды не указаны
- **WHEN** посетитель не приводит значение света и погоды
- **THEN** промпт не утверждает никаких условий света или погоды
- **AND** промпт не описывает воспоминание, о котором посетитель не сообщал

#### Scenario: Ветка вообще не задаёт этот вопрос
- **WHEN** в ветке нет вопроса про свет и погоду
- **THEN** промпт этой ветки не содержит части про свет и погоду

#### Scenario: Цель не указана
- **WHEN** посетитель не приводит цель
- **THEN** промпт не утверждает цель, которую посетитель не выбирал

### Requirement: Каждый отправленный ответ попадает в промпт
Конечная точка SHALL переносить в промпт каждый ответ, отправленный посетителем, во всех ветках, включая ответы, которые текущая реализация читает, но не использует.

#### Scenario: Указан предмет, который посетитель всегда носит с собой
- **WHEN** посетитель отвечает на вопрос о предмете, который всегда при нём
- **THEN** этот ответ присутствует в промпте

#### Scenario: Заполнена ветка «будущее»
- **WHEN** посетитель заполняет ветку «будущее»
- **THEN** указанные им дата, роль, место и действие присутствуют в промпте

### Requirement: Загруженный файл воспоминания используется или явно отклоняется
Конечная точка SHALL NOT молча выбрасывать загруженный файл. Она SHALL либо включить содержимое файла в генерацию, либо вернуть явную ошибку, называющую тип файла, который она не принимает.

#### Scenario: Загружено изображение
- **WHEN** посетитель загружает файл изображения
- **THEN** изображение передаётся языковой модели как вложение
- **AND** сгенерированный ответ отражает содержимое изображения

#### Scenario: Загружен аудиофайл
- **WHEN** посетитель загружает аудиофайл
- **THEN** аудио расшифровывается собственной способностью сервиса распознавать речь
- **AND** полученный текст включается в промпт

#### Scenario: Загружен текстовый документ
- **WHEN** посетитель загружает текстовый документ
- **THEN** текстовое содержимое документа включается в промпт

#### Scenario: Загружен неподдерживаемый тип файла
- **WHEN** посетитель загружает тип файла, который сервис не может использовать
- **THEN** конечная точка возвращает ошибку, называющую неподдерживаемый тип
- **AND** сервис не сообщает об успехе, проигнорировав файл

#### Scenario: Файл не выбрасывается молча
- **WHEN** посетитель загружает любой файл
- **THEN** файл либо появляется в генерации, либо назван в теле ошибки
- **AND** ни один путь выполнения не выбрасывает его без одного из этих двух исходов

### Requirement: Вложения-изображения отправляются модели, умеющей читать изображения
Сервис SHALL отправлять вложение-изображение модели, принимающей изображения на вход, и SHALL сообщать о понятном сбое, а не отправлять изображение модели, которая не может его прочитать.

#### Scenario: Изображение отправлено модели без поддержки изображений
- **WHEN** прикреплено изображение, а настроенная модель отклоняет изображения на входе
- **THEN** сервис использует для этого запроса модель, поддерживающую изображения
- **AND** сгенерированный ответ отражает изображение

#### Scenario: Нет модели, умеющей читать изображения
- **WHEN** прикреплено изображение и ни одна доступная модель не принимает изображения
- **THEN** конечная точка возвращает ошибку, объясняющую, что изображение не удалось обработать
- **AND** конечная точка не возвращает ответ, игнорирующий изображение

### Requirement: Сгенерированный ответ возвращается посетителю
Конечная точка SHALL возвращать посетителю ответ языковой модели по его отправке и SHALL сопоставлять сбой вышестоящего сервиса с кодом ответа, отличающим неудачную генерацию от некорректного запроса.

#### Scenario: Генерация удалась
- **WHEN** языковая модель отвечает успешно
- **THEN** конечная точка возвращает HTTP 200 со сгенерированным ответом

#### Scenario: Вызов языковой модели не удался
- **WHEN** сервис языковой модели возвращает ошибку
- **THEN** конечная точка возвращает HTTP 503
- **AND** тело ответа указывает, что причиной стал вызов языковой модели

#### Scenario: Вызов языковой модели завершился неожиданным сбоем
- **WHEN** вызов языковой модели завершается ошибкой, которую сервис не обрабатывает специально
- **THEN** конечная точка возвращает HTTP 503
- **AND** конечная точка не возвращает ответ о внутренней ошибке, скрывающий настоящую причину
