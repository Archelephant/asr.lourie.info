# Дельта спецификации

## Purpose

Определяет, как конечная точка `POST /asr` разбирает необходимые учётные данные, передаёт загруженный аудиофайл вышестоящему сервису распознавания речи и сообщает результат вызывающему.

## ADDED Requirements

### Requirement: Учётные данные вышестоящего сервиса разбираются из конфигурации деплоя
Сервис SHALL разбирать учётные данные, которые он предъявляет вышестоящему сервису распознавания речи, из конфигурации, предоставленной окружением деплоя, и SHALL NOT зависеть от имени, которого деплой не предоставляет. Деплой, поставляющий эти значения под именами, использовавшимися до перехода на Whisper, SHALL продолжать работать.

#### Scenario: Деплой поставляет секрет под прежним именем
- **WHEN** деплой поставляет учётные данные вышестоящего сервиса под прежним именем переменной окружения
- **THEN** конечная точка разбирает их и передаёт учётные данные вышестоящему сервису
- **AND** конечная точка не сообщает об отсутствующей конфигурации

#### Scenario: Учётные данные отсутствуют в окружении
- **WHEN** учётные данные вышестоящего сервиса не поставляются ни под одним из поддерживаемых имён
- **THEN** конечная точка возвращает ответ «сервис недоступен», называющий недостающую конфигурацию
- **AND** ответ не доходит до вышестоящего сервиса

#### Scenario: Учётные данные поставляются файлом-секретом
- **WHEN** деплой поставляет учётные данные вышестоящего сервиса через подключённый файл-секрет
- **THEN** конечная точка разбирает учётные данные из этого файла
- **AND** учётные данные не оказываются в окружении процесса

### Requirement: Загруженное аудио распознаётся вышестоящим сервисом
Конечная точка SHALL передавать загруженный аудиофайл вышестоящему сервису распознавания речи и SHALL возвращать распознанный текст вместе с запрошенным языком.

#### Scenario: Успешное распознавание
- **WHEN** клиент отправляет корректный аудиофайл
- **THEN** конечная точка возвращает HTTP 200 с телом JSON, содержащим распознанный `text` и запрошенный `language`

#### Scenario: Вышестоящий сервис не вернул текста
- **WHEN** вышестоящий сервис возвращает успешный ответ с пустым текстом
- **THEN** конечная точка возвращает HTTP 200 с пустым полем `text`
- **AND** конечная точка не считает пустой результат ошибкой

### Requirement: Учётные данные вышестоящего сервиса проверяются при старте
Сервис SHALL при старте проверять, что вышестоящий сервис распознавания речи принимает настроенные учётные данные, и SHALL отличать отклонённые учётные данные от недостижимого вышестоящего сервиса.

#### Scenario: Вышестоящий сервис отклоняет учётные данные
- **WHEN** вышестоящий сервис отвечает на проверку при старте отказом в аутентификации
- **THEN** при старте сообщается, что учётные данные отклонены
- **AND** при старте не сообщается, что вышестоящий сервис лишь недостижим

#### Scenario: Вышестоящий сервис недостижим
- **WHEN** во время проверки при старте до вышестоящего сервиса не удаётся достучаться
- **THEN** при старте сообщается, что вышестоящий сервис недостижим
- **AND** при старте не сообщается, что учётные данные отклонены

#### Scenario: Вышестоящий сервис принимает учётные данные
- **WHEN** вышестоящий сервис отвечает на проверку при старте любым ответом, кроме отказа в аутентификации
- **THEN** при старте сообщается, что учётные данные приняты

### Requirement: Сбои вышестоящего сервиса различаются кодами ответа
Конечная точка SHALL сопоставлять сбои вышестоящего сервиса с кодами ответа, которые различают отклонённый запрос, отклонённые сервисом учётные данные и недоступный вышестоящий сервис.

#### Scenario: Вышестоящий сервис отклоняет запрос как некорректный
- **WHEN** вышестоящий сервис отвечает кодом ошибки клиента, указывающим, что запрос некорректен
- **THEN** конечная точка возвращает HTTP 400
- **AND** тело ответа содержит объяснение вышестоящего сервиса

#### Scenario: Вышестоящий сервис отклоняет учётные данные сервиса
- **WHEN** вышестоящий сервис отвечает отказом в аутентификации
- **THEN** конечная точка возвращает HTTP 502
- **AND** тело ответа указывает, что причиной являются учётные данные к вышестоящему сервису

#### Scenario: Вышестоящий сервис недоступен
- **WHEN** до вышестоящего сервиса не удаётся достучаться или он не отвечает вовремя
- **THEN** конечная точка возвращает HTTP 503

### Requirement: Передаваемый тип файла соответствует загруженному файлу
Конечная точка SHALL передавать загруженный файл с типом, определённым по его собственному расширению и содержимому, и SHALL NOT помечать любую загрузку одним фиксированным аудиотипом.

#### Scenario: Загрузка MP3
- **WHEN** клиент загружает файл MP3
- **THEN** запрос к вышестоящему сервису объявляет тип MP3
- **AND** запрос не объявляет тип WAV

#### Scenario: Загрузка с нераспознаваемым расширением
- **WHEN** клиент загружает файл, расширение которого не распознаётся
- **THEN** конечная точка передаёт его с общим двоичным типом
- **AND** вышестоящий сервис сохраняет возможность отклонить его по собственным правилам

### Requirement: Вызовы вышестоящего сервиса ограничены
Конечная точка SHALL ограничивать и число попыток обращения к вышестоящему сервису, и затраченное на них время, чтобы не работающий вышестоящий сервис не исчерпывал запрос бесконечно.

#### Scenario: Повторяющиеся сбои вышестоящего сервиса
- **WHEN** каждая попытка обращения к вышестоящему сервису заканчивается неудачей
- **THEN** конечная точка сдаётся после ограниченного числа попыток
- **AND** конечная точка отвечает в течение ограниченного времени

#### Scenario: Временный сбой вышестоящего сервиса
- **WHEN** попытка заканчивается временной сетевой ошибкой, а последующая удаётся
- **THEN** конечная точка возвращает результат успешной попытки
